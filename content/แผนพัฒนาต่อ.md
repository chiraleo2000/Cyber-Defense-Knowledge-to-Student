# แผนพัฒนาต่อ (Roadmap) และสิ่งที่มีอยู่ตอนนี้

> หน้านี้แยกให้ชัดเจนระหว่าง **"สิ่งที่ใช้งานได้จริงบนเว็บตอนนี้"** กับ **"แผนพัฒนาในอนาคต (ยังไม่ทำ/กำลังคิด)"**
> เพื่อความโปร่งใส — ผู้อ่านจะได้ไม่เข้าใจผิดว่าฟีเจอร์อนาคตมีให้ใช้แล้ว

ทั้งหมดนี้เปิดใช้งานได้ทันทีบนเว็บไซต์ (static site บน GitHub Pages ไม่ต้องติดตั้งอะไร):

### เว็บไซต์ข้อมูล
- **หน้าเนื้อหาภาษาไทย 11 หน้า** — สถิติ, คดีจริงในไทย, มุมมองระดับโลก, การวิเคราะห์สถานการณ์,
  คู่มือรับมือ, ข้อเสนอแนะเชิงนโยบาย, แหล่งที่มาของสื่อ, แบบสำรวจ, [รู้ทันสคริปต์มิจฉาชีพ](รู้ทันสคริปต์มิจฉาชีพ.md),
  [ถูกหลอกแล้วทำอย่างไร](ถูกหลอกแล้วทำอย่างไร.md) — ทุกหน้ามีทั้งฉบับอ่านบนเว็บและ **ไฟล์ PDF ดาวน์โหลด**
- **โปสเตอร์ 5 สัญญาณอันตราย** (พร้อมโพสต์ Facebook/Instagram) ที่หน้า[ดาวน์โหลด](ดาวน์โหลด.md)
- ทุกตัวเลข/คดีมี **ลิงก์แหล่งอ้างอิงที่ตรวจสอบได้จริง**

### เว็บแอปประเมินความเสี่ยง ([เปิดใช้งาน](webapp/))
ทำงานในเบราว์เซอร์ล้วน ๆ ไม่ส่งข้อมูลออกนอกเครื่อง (ยกเว้นผู้ช่วย AI):

| ฟีเจอร์ | สถานะ |
|---|---|
| แบบทดสอบประเมินความเสี่ยง | ✅ ใช้ได้ |
| ตรวจสอบสัญญาณวิดีโอคอลปลอม | ✅ ใช้ได้ |
| สแกนข้อความสนทนาหาคำ/วลีเสี่ยง | ✅ ใช้ได้ |
| ตรวจสอบภาพ/เอกสาร (EXIF + เกณฑ์เอกสารปลอม) | ✅ ใช้ได้ |
| ถอดเสียงสนทนาเป็นข้อความ (Whisper ในเบราว์เซอร์) | ✅ ใช้ได้ |
| ผู้ช่วย AI แบบแชท (โมเดล Pathumma) | ⚙️ ใช้ได้เมื่อ deploy worker (มิฉะนั้นตอบแบบออฟไลน์) |

*หมายเหตุ: ผู้ช่วย AI ต้องตั้งค่า Cloudflare Worker + คีย์ ThaiLLM ก่อน (ดู `AGENT-SETUP.md`) —
ถ้ายังไม่ตั้ง เว็บแอปยังใช้งานได้ทุกส่วน เพียงแต่ผู้ช่วย AI จะตอบด้วยกฎเบื้องต้นแบบออฟไลน์แทน*

## 🚧 ส่วนที่ 2: แผนพัฒนาในอนาคต (ยังไม่ทำ — เป็นแนวคิด/ข้อเสนอ)

ส่วนนี้ยังเป็น **แนวคิด** ยังไม่มีให้ใช้งานจริง นำเสนอไว้เพื่อเป็นทิศทางพัฒนาและเปิดให้ผู้สนใจต่อยอด

### 2.1 แอปมือถือ "ผู้พิทักษ์สาย" — วิเคราะห์การโทรแบบเรียลไทม์

ปัญหาปัจจุบันคือ กว่าเหยื่อจะรู้ตัวก็โอนเงินไปแล้ว จึงเสนอแนวคิดแอปมือถือที่ **เฝ้าฟังและวิเคราะห์
สายสนทนาแบบสด (streaming)** เพื่อเตือนหรือช่วยตัดสายก่อนที่เหยื่อจะตกอยู่ในภาวะถูกครอบงำ

**หลักการทำงาน (ออกแบบให้เคารพความเป็นส่วนตัว):**

1. **กรองที่ต้นทาง** — ทำงานเฉพาะเมื่อรับสายจาก **เบอร์แปลกหน้า/ไม่อยู่ในรายชื่อ** หรือสาย VoIP/ต่างประเทศ
2. **ถอดเสียงในเครื่อง (on-device)** — แปลงเสียงเป็นข้อความด้วยโมเดลที่รันบนมือถือเอง **ไม่ส่งเสียงขึ้นคลาวด์**
   เพื่อความเป็นส่วนตัว (แนวทางเดียวกับที่เว็บแอปนี้ใช้ Whisper ในเบราว์เซอร์)
3. **วิเคราะห์รูปแบบสคริปต์ (NLP)** — จับคำ/วลีเสี่ยงแบบเรียลไทม์ เช่น "บัญชีม้า", "คดีฟอกเงิน",
   "ห้ามบอกใคร", "โอนเข้าบัญชีกลาง", "เปิดกล้องไว้" แล้วให้ **คะแนนความเสี่ยงสะสม**
4. **เตือนทันทีบนหน้าจอ** — เมื่อคะแนนถึงระดับเสี่ยง แสดงแถบเตือนสีแดง เช่น
   *"⚠️ บทสนทนานี้มีรูปแบบเดียวกับแก๊งคอลเซ็นเตอร์ — อย่าโอนเงิน วางสายแล้วโทร 1441"*
5. **ช่วยตัดสาย/หน่วงเวลา** — เสนอปุ่มตัดสายเด่นชัด และ (ถ้าผู้ใช้เปิดไว้) เตือนซ้ำเมื่อกำลังจะเปิดแอปธนาคาร
6. **ปุ่ม SOS** — เชื่อมโทรออก AOC 1441 หรือแจ้งผู้ติดต่อฉุกเฉินพร้อมสรุปบทสนทนาที่ตรวจพบ

**ทำได้จริงแค่ไหน / ข้อควรระวัง:**

- **ทำได้ในเชิงเทคนิค** — โทรศัพท์รุ่นใหม่รันโมเดลถอดเสียง + NLP บนเครื่องได้แล้ว และการตรวจจับ
  ด้วยคำสำคัญ/รูปแบบไม่ต้องใช้คลาวด์
- **ต้องเคารพความเป็นส่วนตัวสูงสุด** — ประมวลผลในเครื่อง, ขออนุญาตชัดเจน, ไม่บันทึก/ส่งเสียงออก,
  เปิด-ปิดได้เอง เพื่อไม่ให้กลายเป็นเครื่องมือดักฟัง
- **เป็นตัวช่วย ไม่ใช่คำตัดสิน** — ควรออกแบบให้ "เตือนและให้ทางเลือก" ไม่ตัดสายเองโดยพลการ เพื่อลด
  การเตือนผิดพลาด (false positive) กับสายปกติ
- **ข้อจำกัดปัจจุบัน** — ความแม่นยำการถอดเสียงภาษาไทยแบบเรียลไทม์ยังต้องพัฒนา และต้องระวังมิจฉาชีพ
  ปรับคำเลี่ยงการตรวจจับ จึงควรใช้ควบคู่กับการให้ความรู้เสมอ

> เว็บแอป "เช็คก่อนโอน" ปัจจุบันเป็น **ต้นแบบระดับเริ่มต้น** ของแนวคิดนี้ (สแกนข้อความ + ถอดเสียงในเบราว์เซอร์
> + ผู้ช่วย AI) — ทดลองได้ที่[เว็บแอป](webapp/) แล้วต่อยอดสู่แอปมือถือเต็มรูปแบบได้ในอนาคต

### 2.2 แผนพัฒนาอื่น ๆ ที่เสนอไว้

| แผน | รายละเอียด | สถานะ |
|---|---|---|
| ผู้ช่วย AI Pathumma แบบเต็ม | เชื่อม worker + ThaiLLM ให้ตอบด้วยโมเดลจริง (มีโครงสร้างพร้อมแล้ว) | ⚙️ รอ deploy |
| LINE Chatbot | ตอบคำถามภัยหลอกลวงอัตโนมัติผ่าน LINE OA | 🚧 แนวคิด |
| Dashboard เฝ้าระวังระดับสถาบัน | สรุปแนวโน้มความเสี่ยงแบบเคารพความเป็นส่วนตัว (opt-in) | 🚧 แนวคิด |
| ค้นหาเต็มเนื้อหา (full-text search) | ตอนนี้ค้นเฉพาะชื่อหัวข้อในเมนู | 🚧 แนวคิด |
| ถอดเสียงภาษาไทยแม่นยำขึ้น | ใช้โมเดล finetune เฉพาะไทย (เช่น Thonburian Whisper) เมื่อรันในเบราว์เซอร์ได้ | 🚧 รอเทคโนโลยี |
| ชุดสื่อ/คลิปสั้น (Reels/TikTok) | จำลองเคสจริงเพื่อเผยแพร่ในโซเชียล | 🚧 แนวคิด |

*(ดูกรอบแผนเชิงระบบ 3 เสาหลัก x 3 ระดับ และไทม์ไลน์ดำเนินงานฉบับเต็มได้ที่*
