# แหล่งที่มาของสื่อ และวิธีตรวจสอบความน่าเชื่อถือของข่าว

เว็บไซต์นี้ยึดหลัก **ทุกตัวเลขและทุกคดีต้องมีลิงก์อ้างอิงที่เปิดอ่านได้จริง** หน้านี้รวบรวมภาพรวมของแหล่งข้อมูล
ทั้งหมดที่ใช้ในเว็บไซต์ พร้อมคำแนะนำสำหรับผู้อ่านที่ต้องการตรวจสอบข่าวสารเกี่ยวกับภัยหลอกลวงด้วยตนเอง

## หน่วยงานทางการที่อ้างอิงในเว็บไซต์นี้

| หน่วยงาน | บทบาท | ช่องทางติดต่อ |
|---|---|---|
| ศูนย์ปฏิบัติการแก้ไขปัญหาอาชญากรรมออนไลน์ (AOC 1441) | รับแจ้งเหตุอาชญากรรมออนไลน์ ประสานอายัดบัญชีฉุกเฉิน | สายด่วน **1441** |
| ศูนย์ต่อต้านการฉ้อโกงออนไลน์ (ACSC) — สำนักงานตำรวจแห่งชาติ | เผยแพร่สถิติคดีออนไลน์ ประสานหน่วยงานปราบปราม | [thaipoliceonline.go.th](https://www.thaipoliceonline.go.th) |
| กองบัญชาการตำรวจสืบสวนสอบสวนอาชญากรรมทางเทคโนโลยี (บช.สอท. / ตำรวจไซเบอร์) | สืบสวนคดีอาชญากรรมไซเบอร์โดยตรง | สายด่วน **1441** / โทร. **191** |
| สำนักงานคณะกรรมการกำกับหลักทรัพย์และตลาดหลักทรัพย์ (ก.ล.ต.) | ตรวจสอบว่าแพลตฟอร์มลงทุนได้รับอนุญาตถูกต้องหรือไม่ | [sec.or.th](https://www.sec.or.th) |
| กรมประชาสัมพันธ์ (PRD) | เผยแพร่ความรู้ด้านจิตวิทยาการหลอกลวงและการป้องกันภัย | [prd.go.th](https://www.prd.go.th) |
| FBI Internet Crime Complaint Center (IC3) — สหรัฐอเมริกา | สถิติอาชญากรรมไซเบอร์ระดับสากลที่ใช้ในหน้าข้อมูลต่างประเทศ | [ic3.gov](https://www.ic3.gov) |

## สำนักข่าวที่ถูกอ้างอิงในหน้าคดีจริง

รายการคดีจริงในหน้า [สถิติและคดีจริงในประเทศไทย](คดีจริงในไทย.md) อ้างอิงจากสำนักข่าวไทยที่มีกอง
บรรณาธิการตรวจสอบข้อเท็จจริงตามมาตรฐานวิชาชีพ ได้แก่ Thai PBS, ไทยรัฐ, ข่าวสด, มติชน, เดลินิวส์,
คมชัดลึก, แนวหน้า, ช่อง 7, อมรินทร์ทีวี, FM91, LINE TODAY และประกาศจากหน่วยงานราชการโดยตรง (กรมประชาสัมพันธ์)
ทุกรายการมีลิงก์ต้นฉบับกำกับ — หากลิงก์ใดเสียหรือถูกลบในภายหลัง กรุณาแจ้งผ่าน Issue บน GitHub
repository นี้เพื่อให้ทีมงานอัปเดต

## วิธีตรวจสอบข่าวหรือคำเตือนภัยหลอกลวงด้วยตนเอง

ก่อนเชื่อและแชร์ข่าวหรือคำเตือนเกี่ยวกับภัยหลอกลวงต่อ แนะนำให้ตรวจสอบตามลำดับนี้:

1. **ดูชื่อสำนักข่าว/หน่วยงานต้นทาง** — ข่าวที่น่าเชื่อถือควรระบุชื่อสำนักข่าวหรือหน่วยงานที่ตรวจสอบได้ ไม่ใช่
   แค่ภาพแคปเจอร์หรือข้อความที่ส่งต่อกันในแชท

2. **ตรวจสอบวันที่เผยแพร่** — ข่าวเตือนภัยบางเรื่องถูกแชร์ซ้ำหลังผ่านไปหลายปีจนข้อมูลล้าสมัย (เช่น เบอร์
   โทรศัพท์หรือชื่อแอปที่เปลี่ยนไปแล้ว)

3. **ค้นหาข่าวเดียวกันจากมากกว่า 1 แหล่ง** — หากเป็นเหตุการณ์จริงที่มีนัยสำคัญ มักมีสำนักข่าวหลายแห่ง
   รายงานตรงกัน ไม่ใช่มีเพียงแหล่งเดียว

4. **ตรวจสอบกับหน่วยงานทางการโดยตรง** — สำหรับคำเตือนเกี่ยวกับกลโกงรูปแบบใหม่ ให้ตรวจสอบกับ AOC 1441
   หรือเพจ Facebook ทางการของตำรวจไซเบอร์ก่อนเชื่อและแชร์ต่อ

5. **ระวังคำเตือนที่ "เร่งให้แชร์ด่วน" โดยไม่มีแหล่งอ้างอิง** — ข้อความหลอกลวงบางประเภทใช้ "คำเตือนภัยปลอม"
   เป็นเครื่องมือหลอกลวงอีกชั้นหนึ่งเช่นกัน

## ร่วมปรับปรุงแหล่งข้อมูล

เว็บไซต์นี้เป็น open source — หากพบลิงก์เสีย ข้อมูลคลาดเคลื่อน หรือมีคดี/สถิติใหม่ที่ตรวจสอบแหล่งที่มาได้
ต้องการเพิ่มเข้ามา สามารถเปิด Pull Request หรือ Issue บน GitHub repository ได้โดยตรง (ดูวิธีการในไฟล์
`README.md` ที่ราก repository)
