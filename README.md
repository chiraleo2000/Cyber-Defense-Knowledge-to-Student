# เช็คก่อนโอน — โปรเจกต์รวมข้อมูล/เครื่องมือป้องกันภัยหลอกลวงออนไลน์

โปรเจกต์นี้รวบรวม 3 ส่วนไว้ในที่เดียว สำหรับใช้ป้องกัน/ให้ความรู้เรื่องภัยหลอกลวง
(แก๊งคอลเซ็นเตอร์, Romance Scam, หลอกลงทุน ฯลฯ) แก่นักศึกษาและบุคคลทั่วไป:

1. **เว็บไซต์ข้อมูล (GitHub Pages)** — `docs/` : สถิติ คดีจริง (ในประเทศ+ต่างประเทศ) การวิเคราะห์
   คำแนะนำ คู่มือรับมือ แหล่งอ้างอิงสื่อ และไฟล์ดาวน์โหลด (PDF + โปสเตอร์) ทั้งหมดอยู่ในรูปแบบ
   Markdown ที่ render เป็นเว็บ + มีเวอร์ชัน PDF ให้ดาวน์โหลด/พิมพ์
2. **เว็บแอปประเมินความเสี่ยง** — `docs/webapp/index.html` (ต้นฉบับ: `webapp-source/`) : แบบทดสอบ
   ประเมินความเสี่ยง, เครื่องมือตรวจสอบเบอร์/ลิงก์, ผู้ช่วย AI แบบแชท, ถอดเสียงไฟล์เสียงด้วย AI
   โอเพนซอร์ส (Whisper) ทำงานในเบราว์เซอร์ล้วนๆ ไม่ต้องมีเซิร์ฟเวอร์
3. **Agent Proxy (Cloudflare Worker)** — `worker/` : ตัวกลางฝั่งเซิร์ฟเวอร์สำหรับฟีเจอร์ "ผู้ช่วย AI"
   เก็บ API key ไว้อย่างปลอดภัย ไม่ให้รั่วไหลออกไปฝั่ง client หรือ commit ขึ้น git

ทุกไฟล์ในเว็บไซต์/เว็บแอปนี้เป็น **static site ล้วนๆ** — ไม่มี backend, ไม่มีฐานข้อมูล
รันได้ฟรีบน GitHub Pages ทั้งหมด ยกเว้นฟีเจอร์ "ผู้ช่วย AI" ที่ต้อง deploy Worker แยกต่างหาก (ตัวเลือก
ไม่บังคับ — ถ้าไม่ deploy เว็บแอปจะใช้งานได้ปกติทุกส่วน เพียงแต่ผู้ช่วย AI จะตอบแบบออฟไลน์/กฎเบื้องต้นแทน)

## โครงสร้างโปรเจกต์

```
.
├── docs/                     ← เนื้อหาที่ GitHub Pages จะเผยแพร่ (ตั้ง Pages ให้ deploy จากโฟลเดอร์นี้)
│   ├── index.html            ← หน้าเว็บหลัก (SPA เรนเดอร์ markdown)
│   ├── content/*.md          ← เนื้อหาทุกหน้า (แก้ไขที่นี่)
│   ├── assets/                ← CSS, JS, ฟอนต์ (self-hosted ทั้งหมด ไม่พึ่ง CDN ภายนอก)
│   ├── downloads/             ← PDF + โปสเตอร์ (พร้อมโพสต์ Facebook/Instagram)
│   └── webapp/index.html      ← สำเนาเว็บแอปที่ให้บริการจริงบน Pages
├── webapp-source/
│   └── check-kon-oon.html    ← ต้นฉบับเว็บแอป (แก้ที่นี่ แล้วคัดลอกไปทับ docs/webapp/index.html)
├── worker/                    ← Cloudflare Worker (Agent Proxy) — ดู worker/README.md
└── README.md                  ← ไฟล์นี้
```

**สำคัญ**: `docs/webapp/index.html` เป็นสำเนาที่เผยแพร่จริง ส่วน `webapp-source/check-kon-oon.html`
เป็นต้นฉบับสำหรับแก้ไข เมื่อแก้ไฟล์ต้นฉบับแล้วให้คัดลอกทับไฟล์ในตำแหน่งที่เผยแพร่ด้วยเสมอ:

```bash
cp webapp-source/check-kon-oon.html docs/webapp/index.html
```
## ความโปร่งใสของเนื้อหา (สำคัญ — โปรดอ่านก่อนเผยแพร่)

เพื่อไม่ให้มีข้อมูลเท็จหรือสถิติที่แต่งขึ้นปะปนอยู่ในเนื้อหา จึงขอสรุปข้อจำกัดที่ตั้งใจไว้ตั้งแต่แรก:

- **สถิติ/คดีในประเทศไทย** (`docs/content/domestic-cases.md`) — อ้างอิงจากข่าวและแหล่งข้อมูล
  ที่ตรวจสอบแล้วเท่านั้น มีลิงก์แหล่งที่มากำกับทุกรายการ
- **มุมมองระดับโลก** (`docs/content/international-cases.md`) — ตั้งใจใส่เฉพาะสถิติที่ยืนยันได้จริง
  (FBI IC3 Annual Report 2024) และคำอธิบายรูปแบบภัยทั่วไปเท่านั้น **ไม่ได้ใส่กรณีศึกษาต่างประเทศ
  แบบเจาะจง** เนื่องจากไม่สามารถตรวจสอบแหล่งข่าวเฉพาะกรณีได้ครบถ้วนในขณะจัดทำ — หากต้องการเพิ่ม
  กรณีศึกษาต่างประเทศ แนะนำให้ผู้ดูแลเว็บไซต์ตรวจสอบแหล่งข่าวเองก่อนเพิ่มเนื้อหา
- **แบบสำรวจ** (`docs/content/survey-report.md`) — ไฟล์นี้เป็น **แบบสำรวจพร้อมใช้** (คำถาม + แผนการ
  วิเคราะห์ + คำแนะนำขนาดกลุ่มตัวอย่าง) **ยังไม่มีการเก็บข้อมูลจริง** เมื่อเก็บข้อมูลจริงแล้วให้แทนที่
  เนื้อหาในไฟล์นี้ด้วยผลสำรวจจริง

## ข้อจำกัดที่ควรทราบ

- **Speech-to-Text (Whisper)**: ทำงานในเบราว์เซอร์ล้วนๆ ผ่าน transformers.js (`Xenova/whisper-tiny`)
  ตามที่เลือกไว้ว่าต้องเป็นโอเพนซอร์สและรันได้บน GitHub Pages (ไม่มีเซิร์ฟเวอร์) — โมเดลนี้เป็น
  multilingual ทั่วไป ความแม่นยำภาษาไทยจะต่ำกว่าโมเดลที่ finetune เฉพาะภาษาไทยโดยเฉพาะ (เช่น
  Thonburian Whisper ซึ่งยังไม่มีเวอร์ชันที่รันในเบราว์เซอร์ได้) มีข้อความแจ้งเตือนเรื่องนี้ในหน้าเว็บแอปแล้ว
- **ผู้ช่วย AI**: ต้อง deploy worker (ขั้นตอนที่ 3 ด้านบน) จึงจะเชื่อมโมเดลจริงได้ ก่อน deploy จะตอบแบบ
  กฎเบื้องต้น (offline) ที่เตรียมไว้ล่วงหน้า
- **การค้นหาในแถบด้านข้าง**: กรองตามชื่อหัวข้อในเมนูเท่านั้น (ยังไม่ค้นในเนื้อหาเต็มของหน้า) — หากต้องการ
  ขยายให้ค้นเนื้อหาด้วย สามารถแก้ไขฟังก์ชัน `buildNav()` ใน `docs/assets/js/app.js` เพิ่มเติมได้

## ใบอนุญาตใช้งาน

ไฟล์ทั้งหมดในโปรเจกต์นี้ (เนื้อหา, โปสเตอร์, โค้ด) เผยแพร่แบบเปิดให้นำไปใช้ ปรับแก้ หรือแชร์ต่อได้ฟรี
เพื่อประโยชน์ด้านความปลอดภัยสาธารณะ — โปรดตรวจสอบแหล่งอ้างอิงในแต่ละหน้าก่อนนำสถิติไปอ้างอิงต่อ
