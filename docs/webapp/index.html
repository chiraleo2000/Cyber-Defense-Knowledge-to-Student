คดีส่วนใหญ่ใช้วิดีโอคอลสร้างความน่าเชื่อถือ ติ๊กสิ่งที่พบเจอ เพื่อประเมินว่าน่าจะเป็นการจัดฉากมากน้อยเพียงใด

เคสจริง: นักศึกษาแพทย์ ป.เอก ถูกวิดีโอคอล LINE จากผู้แต่งกายคล้ายตำรวจ พร้อมเสียงวิทยุสื่อสารประกอบฉาก ก่อนสูญเงินกว่า 10.9 ล้านบาท เหตุการณ์จริง 22–25 ส.ค. 2569, กรุงเทพฯ

หลักการสำคัญที่สุด: หน่วยงานราชการที่แท้จริงจะไม่มีวันขอให้โอนเงินหรือถอนเงินสดผ่านโทรศัพท์/วิดีโอคอลเพื่อ "ตรวจสอบความบริสุทธิ์" ไม่ว่ากรณีใดก็ตาม และจะไม่ใช้ LINE, Facetime หรือ Telegram ส่วนตัวในการสอบสวนคดี

รูปแบบที่พบบ่อย: แก๊งคอลเซ็นเตอร์มักส่งภาพ "หมายจับ" หรือ "หนังสือราชการ" ที่ใช้ตราครุฑปลอมทาง LINE ไม่มีเลขที่หนังสือ ไม่มีลายเซ็นที่ตรวจสอบได้ และเป็นภาพที่ถูกตัดต่อ/แก้ไขด้วยโปรแกรมกราฟิก อ้างอิง: รูปแบบที่ ACSC และตำรวจไซเบอร์เตือนซ้ำหลายครั้งในปี 2568–2569

ถอดเสียงสนทนา แล้วสแกนหาคำเข้าข่าย

อัดเสียงหรืออัปโหลดไฟล์เสียงที่บันทึกไว้ ถอดเป็นข้อความ แล้วส่งต่อไปสแกนหาคำเข้าข่ายหลอกลวงแบบเดียวกับโมดูลข้อความ

ทำไมต้องถอดเสียง: คนร้ายมักย้ำวลีข่มขู่และควบคุมพฤติกรรมซ้ำๆ เช่น "ห้ามบอกใคร" "ห้ามวางสาย" — การถอดเป็นข้อความช่วยให้เห็นรูปแบบเหล่านี้ชัดเจนขึ้นกว่าการฟังสดขณะตกใจ อ้างอิงพฤติกรรมควบคุมเหยื่อที่พบซ้ำในหลายคดี
การถอดเสียงพูดสดขึ้นอยู่กับสิทธิ์ไมโครโฟนที่เบราว์เซอร์/หน้านี้อนุญาต หากปุ่มด้านล่างใช้ไม่ได้ ให้ใช้วิธี "อัปโหลดไฟล์เสียง" แล้วฟังพร้อมพิมพ์ข้อความลงช่องด้านล่างแทนได้ทันที — การสแกนหาคำเข้าข่ายทำงานเหมือนกันทุกวิธี
ใช้โมเดลโอเพนซอร์ส Whisper ประมวลผลในเบราว์เซอร์ของคุณเองทั้งหมด (ไม่มีการอัปโหลดไฟล์เสียงออกจากเครื่อง) ต้องดาวน์โหลดโมเดลครั้งแรก (~40-80MB) จึงอาจใช้เวลาสักครู่ และความแม่นยำภาษาไทยอาจต่ำกว่าการพิมพ์ฟังเองหรือบริการเฉพาะภาษาไทย
เบราว์เซอร์นี้ไม่รองรับหรือไม่อนุญาตให้ใช้การถอดเสียงพูดอัตโนมัติ — ฟังไฟล์เสียงด้านล่างแล้วพิมพ์ข้อความที่ได้ยินลงในช่องด้านล่างแทนได้

ผู้ช่วย AI ตอบคำถามเบื้องต้น

พิมพ์อธิบายสถานการณ์ที่สงสัย แล้วผู้ช่วยจะช่วยประเมินเบื้องต้นและแนะนำขั้นตอนถัดไป — ไม่ใช่บริการฉุกเฉิน หากอยู่ในสถานการณ์อันตรายให้โทร 1441/191 ทันที

กำลังตรวจสอบการเชื่อมต่อผู้ช่วย AI…
ข้อความที่พิมพ์จะถูกส่งไปยังบริการผู้ช่วย AI ที่ตั้งค่าไว้ (ผ่านตัวกลางที่ไม่เก็บ API key ไว้ฝั่งเว็บ) เพื่อประมวลผลคำตอบเท่านั้น — หากยังไม่ได้ตั้งค่าผู้ช่วย AI ระบบจะตอบด้วยคำแนะนำพื้นฐานแบบออฟไลน์แทน คำแนะนำจากผู้ช่วยเป็นเพียงข้อมูลเบื้องต้น ไม่ใช่คำวินิจฉัยทางกฎหมายหรือการเงิน
โครงการไซเบอร์ป้องกัน นศ. ถูกหลอก ข้อมูลอ้างอิงจาก ACSC, AOC 1441, สำนักงานตำรวจแห่งชาติ และรายงานข่าว 2568–2569
