# แผนพัฒนาต่อ (Roadmap) และสิ่งที่มีอยู่ตอนนี้

> หน้านี้แยก 3 ชั้น เพื่อไม่ให้ปนกัน:
> **(ก) สิ่งที่เปิดใช้บนเว็บไซต์แล้ว** · **(ข) โค้ดแอป Flutter ในโฟลเดอร์ `mobile/` ที่รันจากเครื่องได้ แต่ยังไม่ลงสโตร์**
> · **(ค) ผู้พิทักษ์สาย Phase 2 ซึ่งมีแค่หน้าทดลองแบบ opt-in ยังไม่ใช่ตัวดักสายที่ใช้งานได้ และไม่ตัดสายอัตโนมัติ**

---

## ✅ ส่วนที่ 1: สิ่งที่เปิดใช้บนเว็บไซต์แล้ว

### 1A. เว็บไซต์ข้อมูล (GitHub Pages)

ทั้งหมดนี้เปิดใช้งานได้ทันทีบนเว็บไซต์ (static site ไม่ต้องติดตั้งอะไร):

- **หน้าในเมนูเว็บที่เผยแพร่แล้ว** — สถิติและคดีจริงในไทย, มุมมองระดับโลก, การวิเคราะห์สถานการณ์,
  คู่มือรับมือ, ข้อเสนอแนะเชิงนโยบาย, แหล่งที่มาของสื่อ, แบบสำรวจ, ข่าวถึงต้น พ.ย. 2569,
  [รู้ทันสคริปต์มิจฉาชีพ](รู้ทันสคริปต์มิจฉาชีพ.md),
  [ถูกหลอกแล้วทำอย่างไร](ถูกหลอกแล้วทำอย่างไร.md),
  [ใช้บนมือถือ](ใช้บนมือถือ.md) และหน้านี้ — ทุกหน้ามีทั้งฉบับอ่านบนเว็บและ **ไฟล์ PDF ดาวน์โหลด**
- **โปสเตอร์ 5 สัญญาณอันตราย** (พร้อมโพสต์ Facebook/Instagram) ที่หน้า[ดาวน์โหลด](ดาวน์โหลด.md)
- ทุกตัวเลข/คดีมี **ลิงก์แหล่งอ้างอิงที่ตรวจสอบได้จริง**

### 1B. เว็บแอปประเมินความเสี่ยง ([เปิดใช้งาน](webapp/))

ทำงานในเบราว์เซอร์ล้วน ๆ ไม่ส่งข้อมูลออกนอกเครื่อง (ยกเว้นผู้ช่วย AI):

| ฟีเจอร์ | สถานะ |
|---|---|
| แบบทดสอบประเมินความเสี่ยง | ✅ ใช้ได้ |
| ตรวจสอบสัญญาณวิดีโอคอลปลอม | ✅ ใช้ได้ |
| สแกนข้อความสนทนาหาคำ/วลีเสี่ยง | ✅ ใช้ได้ |
| ตรวจสอบภาพ/เอกสาร (EXIF + เกณฑ์เอกสารปลอม) | ✅ ใช้ได้ |
| ถอดเสียงสนทนาเป็นข้อความ (Whisper ในเบราว์เซอร์) | ✅ ใช้ได้ |
| ผู้ช่วย AI แบบแชท (โมเดล Pathumma) | ⚙️ ใช้ได้เมื่อ deploy worker (มิฉะนั้นตอบแบบออฟไลน์) |

*หมายเหตุ: ผู้ช่วย AI ต้องตั้งค่า Cloudflare Worker + คีย์ ThaiLLM ก่อน (ดู `AGENT-SETUP.md`) —
ถ้ายังไม่ตั้ง เว็บแอปยังใช้งานได้ทุกส่วน เพียงแต่ผู้ช่วย AI จะตอบด้วยกฎเบื้องต้นแบบออฟไลน์แทน*

## 📱 ส่วนที่ 2: โค้ดในรีโปที่รันได้ แต่ยังไม่ลงสโตร์และไม่ได้อยู่บนเว็บ

### แอปมือถือ Flutter “เช็คก่อนโอน” (Phase 1 / 1.5) — โฟลเดอร์ `mobile/`

ส่วนนี้เป็น **ซอร์สโค้ดในรีโป** สำหรับ Android และ iOS ไม่ได้เผยแพร่บน App Store หรือ Play Store และไม่ได้ฝังในเว็บที่เปิดอยู่ ผู้ใช้ทั่วไปยังใช้เว็บไซต์กับเว็บแอปได้ทันที

**เป้าหมาย Phase 1:** หยุดเงินออกจากบัญชีก่อนโอน — พอร์ตเครื่องมือเดียวกับเว็บแอป ไม่ใช่การวิเคราะห์สายโทรแบบสด

| โมดูล | สถานะในรีโป |
|---|---|
| Quiz หน้าแรก + triage | ✅ โค้ดใน `mobile/` |
| สแกนข้อความ (LEXICON) | ✅ |
| วิดีโอคอล / Romance / ลงทุน / ภาพ+EXIF | ✅ |
| Help/SOS (`tel:1441` / `191` / `1599`) + disclaimer | ✅ |
| Native STT → สแกนเดียวกัน | ✅ (Phase 1.5) |
| ผู้ช่วย AI (worker URL ทางเลือก + ออฟไลน์) | ✅ (Phase 1.5) |
| ผู้พิทักษ์สาย realtime | ❌ **ยังไม่พร้อมใช้งาน** — ดูส่วนที่ 3 |

รันจากเครื่องได้เมื่อมี Flutter SDK: เข้าโฟลเดอร์ `mobile` แล้วสั่ง `flutter pub get`, `flutter test` และ `flutter run`
กติกาซิงก์กฎกับเว็บอยู่ใน README ของโฟลเดอร์นั้น กฎร่วมอยู่ที่ `shared/scam-rules.json`
ซอร์สบน GitHub: [โฟลเดอร์ mobile](https://github.com/chiraleo2000/Cyber-Defense-Knowledge-to-Student/tree/main/mobile)

## 🚧 ส่วนที่ 3: สิ่งที่ยังไม่พร้อมใช้จริง

ส่วนผู้พิทักษ์สายมีหน้าทดลองในแอป Flutter แล้ว แต่ **ยังไม่ใช่ตัวดักสายที่ทำเสร็จ** และยังไม่มีให้ใช้งานจริงบนสายโทร แผนอื่นในตารางด้านล่างยังเป็นแนวคิด

### 3.1 แอปมือถือ "ผู้พิทักษ์สาย" — วิเคราะห์การโทรแบบเรียลไทม์ (**Phase 2**)

> **สถานะ พ.ย. 2569:** มีเพียง **หน้า scaffold ทดลอง (opt-in)** ในแอป Flutter ที่ `mobile/` —
> **ยังไม่เชื่อมต่อสายโทรจริง จะไม่ตัดสายอัตโนมัติ และยังไม่ลงสโตร์**
> อย่าเข้าใจว่า Phase 2 มาพร้อม Phase 1 หรือว่าแอปวางสายให้เองได้แล้ว

ปัญหาปัจจุบันคือ กว่าเหยื่อจะรู้ตัวก็โอนเงินไปแล้ว จึงเสนอแนวคิดแอปมือถือที่ **เฝ้าฟังและวิเคราะห์
สายสนทนาแบบสด (streaming)** เพื่อเตือนให้ผู้ใช้วางสายเองก่อนตกอยู่ในภาวะถูกครอบงำ

**หลักการทำงาน (ออกแบบให้เคารพความเป็นส่วนตัว):**

1. **กรองที่ต้นทาง** — ทำงานเฉพาะเมื่อรับสายจาก **เบอร์แปลกหน้า/ไม่อยู่ในรายชื่อ** หรือสาย VoIP/ต่างประเทศ
2. **ถอดเสียงในเครื่อง (on-device)** — แปลงเสียงเป็นข้อความบนมือถือเอง **ไม่ส่งเสียงขึ้นคลาวด์**
3. **วิเคราะห์รูปแบบสคริปต์ (NLP / LEXICON)** — จับคำ/วลีเสี่ยงแบบเรียลไทม์ แล้วให้ **คะแนนความเสี่ยงสะสม**
4. **เตือนทันทีบนหน้าจอ** — เมื่อคะแนนถึงระดับเสี่ยง แสดงแถบเตือน + ปุ่ม SOS 1441
5. **แนะนำให้วางสาย / ระวังแอปธนาคาร** — แอป **ไม่ตัดสายอัตโนมัติ** (ลด false positive)
6. **ปุ่ม SOS** — เชื่อมโทรออก AOC 1441

**ข้อจำกัดระบบปฏิบัติการ (ต้องระบุชัดเมื่อพัฒนาต่อ):**

- **Android:** Call Screening / Accessibility มีข้อจำกัดสิทธิ์และนโยบายสโตร์
- **iOS:** CallKit โดยทั่วไปไม่ให้อ่านเสียงสายโทรแบบเรียลไทม์ — ออกแบบให้ไม่สัญญาเกินความเป็นไปได้
- ต้องขออนุญาตชัดเจน เปิด-ปิดได้เอง ไม่กลายเป็นเครื่องมือดักฟัง

> เว็บแอปและแอป Flutter Phase 1 เป็น **ต้นแบบ “เช็คก่อนโอน”** (สแกนข้อความ + ถอดเสียง + ผู้ช่วย AI)
> ส่วนผู้พิทักษ์สาย realtime ยังอยู่ Phase 2

### 3.2 แผนพัฒนาอื่น ๆ ที่เสนอไว้

| แผน | รายละเอียด | สถานะ |
|---|---|---|
| ผู้ช่วย AI Pathumma แบบเต็ม | เชื่อม worker + ThaiLLM ให้ตอบด้วยโมเดลจริง (มีโครงสร้างพร้อมแล้ว) | ⚙️ รอ deploy |
| LINE Chatbot | ตอบคำถามภัยหลอกลวงอัตโนมัติผ่าน LINE OA | 🚧 แนวคิด |
| Dashboard เฝ้าระวังระดับสถาบัน | สรุปแนวโน้มความเสี่ยงแบบเคารพความเป็นส่วนตัว (opt-in) | 🚧 แนวคิด |
| ค้นหาเต็มเนื้อหา (full-text search) | ตอนนี้ค้นเฉพาะชื่อหัวข้อในเมนู | 🚧 แนวคิด |
| ถอดเสียงภาษาไทยแม่นยำขึ้น | ใช้โมเดล finetune เฉพาะไทย (เช่น Thonburian Whisper) เมื่อรันในเบราว์เซอร์ได้ | 🚧 รอเทคโนโลยี |
| ชุดสื่อ/คลิปสั้น (Reels/TikTok) | จำลองเคสจริงเพื่อเผยแพร่ในโซเชียล | 🚧 แนวคิด |
