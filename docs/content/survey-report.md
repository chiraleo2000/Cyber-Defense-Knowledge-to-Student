# แบบสำรวจความตระหนักรู้ภัยไซเบอร์ในกลุ่มนักศึกษา

> **สถานะ: แบบสำรวจพร้อมใช้ — ยังไม่มีการเก็บข้อมูลจริง**
> หน้านี้ไม่ใช่รายงานผลสำรวจ เนื่องจากโครงการยังไม่ได้ลงพื้นที่เก็บข้อมูลจากนักศึกษาจริง ทีมงานจึงเลือก
> เผยแพร่ **เครื่องมือสำรวจที่พร้อมนำไปใช้ได้ทันที** พร้อมวิธีการและแผนวิเคราะห์ผล เพื่อให้สถาบันการศึกษา
> หรือทีมงานที่สนใจนำไปเก็บข้อมูลจริงกับกลุ่มนักศึกษาของตนเอง แล้วนำผลมาแทนที่เนื้อหาในหน้านี้ — การใส่
> ตัวเลขผลสำรวจที่ไม่มีการเก็บข้อมูลจริงถือเป็นการให้ข้อมูลเท็จ ซึ่งทีมงานจะไม่ทำ

## วัตถุประสงค์ของแบบสำรวจ

1. วัดระดับความตระหนักรู้ของนักศึกษาต่อรูปแบบกลโกงที่พบบ่อยในไทย (อ้างเจ้าหน้าที่ ขู่คดีฟอกเงิน, บังคับ
   วิดีโอคอลค้าง, หลอกลงทุน, Romance Scam ฯลฯ)
2. ประเมินว่านักศึกษาเคยพบเจอสถานการณ์เข้าข่ายหลอกลวงมาก่อนหรือไม่ และรับมืออย่างไร
3. วัดความรู้จักและความเชื่อมั่นต่อช่องทางความช่วยเหลือที่มีอยู่ (AOC 1441, Hotline มหาวิทยาลัย ฯลฯ)
4. เก็บข้อมูลเพื่อปรับปรุงเนื้อหาเว็บไซต์และเว็บแอปประเมินความเสี่ยงให้ตรงจุดยิ่งขึ้น

## ชุดคำถามที่แนะนำ (นำไปใส่ใน Google Form / LINE OA ได้ทันที)

### ส่วนที่ 1: ข้อมูลทั่วไป (ไม่ระบุตัวตน)

- ชั้นปีที่กำลังศึกษา (ปี 1 / ปี 2 / ปี 3 / ปี 4 / สูงกว่าปริญญาตรี)
- ลักษณะที่พักอาศัย (หอพักในมหาวิทยาลัย / หอพักเอกชนรอบมหาวิทยาลัย / อยู่กับครอบครัว / อื่น ๆ)

### ส่วนที่ 2: ความตระหนักรู้ (ตอบ ใช่ / ไม่ใช่ / ไม่แน่ใจ)

1. เคยได้ยิน/รู้จักคำว่า "แก๊งคอลเซ็นเตอร์" หรือ "Virtual Kidnapping" มาก่อนหรือไม่
2. ทราบหรือไม่ว่าหน่วยงานราชการจริงจะไม่ขอให้โอนเงินผ่านโทรศัพท์เพื่อ "ตรวจสอบความบริสุทธิ์"
3. ทราบหรือไม่ว่าสามารถโทรแจ้ง AOC 1441 เพื่อขออายัดบัญชีฉุกเฉินได้ภายใน 24 ชั่วโมงหลังโอนเงิน
4. เคยเห็นสื่อรณรงค์/โปสเตอร์เตือนภัยหลอกลวงในมหาวิทยาลัยของตนเองหรือไม่

### ส่วนที่ 3: ประสบการณ์ตรง (เลือกตอบเท่าที่สะดวก)

5. เคยได้รับสายอ้างเป็นเจ้าหน้าที่รัฐ/ค่ายมือถือ/ตำรวจ ที่มีลักษณะน่าสงสัยหรือไม่
6. เคยถูกชักชวนลงทุนที่การันตีผลตอบแทนสูงผิดปกติหรือไม่
7. หากเคยเจอสถานการณ์น่าสงสัย รับมืออย่างไร (วางสายทันที / ปรึกษาคนใกล้ตัวก่อน / หลงเชื่อบางส่วน /
   หลงเชื่อและสูญเสียทรัพย์สิน / อื่น ๆ)

### ส่วนที่ 4: ความคิดเห็นต่อเครื่องมือช่วยเหลือ

8. หากมีเว็บแอปให้ตรวจสอบความเสี่ยงด้วยตนเอง (เช่น เว็บแอป "เช็คก่อนโอน" ในโครงการนี้) คิดว่าจะใช้งาน
   หรือไม่ เพราะเหตุใด
9. ข้อเสนอแนะเพิ่มเติมต่อมหาวิทยาลัยหรือหน่วยงานที่เกี่ยวข้อง (คำถามปลายเปิด)

## แผนการวิเคราะห์ผลเมื่อเก็บข้อมูลจริงแล้ว

- รายงานสัดส่วนคำตอบแต่ละข้อ แยกตามชั้นปีและลักษณะที่พักอาศัย เพื่อดูว่ากลุ่มใดมีความตระหนักรู้ต่ำกว่า
- เทียบผลกับสถิติจริงในหน้า [สถิติและคดีจริงในประเทศไทย](domestic-cases.md) ว่าความตระหนักรู้สอดคล้อง
  กับความเสี่ยงจริงหรือไม่
- ใช้คำถามปลายเปิด (ข้อ 9) ปรับปรุงเนื้อหาคู่มือและเว็บแอปในรอบถัดไป
- แนะนำขนาดตัวอย่างขั้นต่ำ 200–300 คนต่อสถาบัน เพื่อให้ผลมีนัยสำคัญทางสถิติในระดับพื้นฐาน

## วิธีนำไปใช้งานจริง

1. คัดลอกชุดคำถามด้านบนไปสร้างเป็น Google Form หรือแบบสอบถามใน LINE OA
2. เผยแพร่ผ่านช่องทางที่นักศึกษาเข้าถึงง่าย เช่น กลุ่มไลน์รุ่น เพจคณะ หรือช่วงกิจกรรมปฐมนิเทศ
3. เมื่อเก็บข้อมูลครบตามจำนวนที่ต้องการ นำผลมาแทนที่เนื้อหาในไฟล์ `docs/content/survey-report.md` นี้
   พร้อมระบุวันที่เก็บข้อมูล จำนวนผู้ตอบ และวิธีการสุ่มตัวอย่าง เพื่อความโปร่งใส
