# เช็คก่อนโอน: ศูนย์ข้อมูลภัยหลอกลวงไซเบอร์สำหรับนักศึกษา

ในช่วง 4 เดือนแรกของปี 2568 ประเทศไทยมีการแจ้งความคดีอาชญากรรมออนไลน์สูงถึง **121,921 คดี**
สร้างความเสียหายรวมกว่า **7,480 ล้านบาท** และนักศึกษาระดับอุดมศึกษาคือหนึ่งในกลุ่มเป้าหมายหลักของ
ขบวนการแก๊งคอลเซ็นเตอร์ เพราะส่วนใหญ่อยู่ลำพังในหอพัก ขาดประสบการณ์เผชิญหน้ากับหน่วยงานบังคับใช้
กฎหมาย และกลัวเสียอนาคตทางการศึกษาหากถูกกล่าวหาว่าพัวพันคดีอาญา

เว็บไซต์นี้รวบรวมสถิติ คดีจริง บทวิเคราะห์ คำแนะนำ และเครื่องมือตรวจสอบความเสี่ยงไว้ในที่เดียว
โดยยึดหลัก **ทุกตัวเลขต้องมีแหล่งอ้างอิงที่ตรวจสอบได้จริง**

## เริ่มต้นที่นี่

- **กำลังสงสัยว่าตนเองหรือคนใกล้ตัวกำลังถูกหลอกอยู่หรือไม่?** → เปิด[เว็บแอปประเมินความเสี่ยง "เช็คก่อนโอน"](webapp/)
  ทันที มีเครื่องมือตรวจสอบวิดีโอคอล สแกนข้อความสนทนา ตรวจสอบภาพ/เอกสาร และถอดเสียงสนทนา
- **ต้องการเข้าใจภาพรวมสถานการณ์** → อ่าน[สถิติและคดีจริงในประเทศไทย](domestic-cases.md) และ
  [มุมมองระดับโลก](international-cases.md)
- **เป็นอาจารย์ ผู้ปกครอง หรือเจ้าหน้าที่มหาวิทยาลัย** → อ่าน[คู่มือรับมือฉบับเต็ม](handbook.md) และ
  [ข้อเสนอแนะเชิงนโยบาย](recommendations.md)
- **ต้องการดาวน์โหลดโปสเตอร์/เอกสารไปเผยแพร่ต่อ** → ไปที่หน้า[ดาวน์โหลด](downloads.md)

## 5 สัญญาณอันตรายที่ต้องรู้

1. **อ้างเป็นเจ้าหน้าที่แต่ไม่มีเลขคดี/เอกสารทางการที่ตรวจสอบได้**
2. **บังคับให้เปิดวิดีโอคอลค้างไว้เป็นเวลานาน** (หลักชั่วโมงถึงหลายวัน)
3. **สั่งห้ามบอกพ่อแม่ เพื่อน หรืออาจารย์ที่ปรึกษา**
4. **ขอให้โอนเงินเข้า "บัญชีกลางตรวจสอบ" หรือถอนเงินสดไปส่งให้คนแปลกหน้า**
5. **เร่งรัดกดดันให้ตัดสินใจอย่างรวดเร็ว ไม่ให้เวลาคิดหรือปรึกษาใคร**

หากพบสัญญาณเหล่านี้ **วางสายทันที** แล้วโทรสายด่วน **AOC 1441** หรือ **191** เพื่อตรวจสอบ
