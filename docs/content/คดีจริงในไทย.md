# สถิติและคดีจริง: ภัยหลอกลวงนักศึกษาในประเทศไทย

> ข้อมูลทั้งหมดในหน้านี้รวบรวมจากรายงานข่าวและสถิติทางการที่เผยแพร่สู่สาธารณะระหว่าง พ.ศ. 2568–2569 อ้างอิงแหล่งข่าวและหน่วยงาน (ACSC, AOC 1441, บช.สอท.) ตามที่ระบุไว้ในแต่ละรายการ คลิกลิงก์เพื่ออ่านต้นฉบับ

## ภาพรวมตัวเลขสำคัญ

| ตัวชี้วัด | ข้อมูล | แหล่งอ้างอิง |
|---|---|---|
| จำนวนคดีออนไลน์รวม (4 เดือนแรก ปี 2568) | **121,921 คดี** | ACSC |
| มูลค่าความเสียหายรวม (4 เดือนแรก) | **7,480 ล้านบาท** | ACSC |
| คดีขู่ทางโทรศัพท์ (แก๊งคอลเซ็นเตอร์) สะสม | **51,678 คดี / 10,761 ล้านบาท** | AOC 1441 |
| มูลค่าความเสียหายเฉลี่ยต่อคดี (กลุ่มเทคนิคขั้นสูง) | **211,686 บาท/คดี** | ACSC |
| สัดส่วนเหยื่อเพศหญิง : เพศชาย | **64% : 36%** | บช.สอท. |
| สัดส่วนเหยื่อช่วงอายุ 18–29 ปี (นักศึกษา) | **รวมประมาณ 31.5%** | ศูนย์บริหารรับแจ้งความออนไลน์ |
| กรอบมูลค่าความเสียหายต่อเคสนักศึกษา | **250,000 – 10,995,000 บาท** | รวบรวมจากคดีจริง 2568–2569 |
| 3 จังหวัดแจ้งความคดีกักขังทิพย์สูงสุด | **กทม. (69) / สมุทรปราการ (24) / นนทบุรี (22)** | ACSC |

## ไทม์ไลน์คดีจริงที่มีการรายงาน (2568–2569)

| วันที่ | ผู้เสียหาย | ลักษณะเหตุการณ์ | มูลค่าความเสียหาย (บาท) |
|---|---|---|---|
| 22–25 ส.ค. 2569 | นักศึกษาแพทย์ ป.เอก (พญาไท, กทม.) | อ้าง AIS/สภ.เมืองเลย ขู่คดีฟอกเงิน หลอกทุนสวิตเซอร์แลนด์ + ม้าเร็วรับเงินสด 3 วัน | 10,995,000 |

| ไม่ระบุวัน 2569 | นักศึกษา ม.มหาสารคาม | หมายจับตราครุฑปลอมทาง LINE ขังตัวเองในโรงแรม (ช่วยได้ทัน) | 0 (ป้องกันสำเร็จ) |

## แหล่งข่าวจริง จัดกลุ่มตามกลลวงที่ใช้
